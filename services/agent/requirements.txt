# Pinned to the versions this was built and tested against.
#
# These were `>=` until the security pass of 2026-08-15, which meant the thing
# that ran in the container was whatever had been released that morning, and not
# the thing any test had ever run against. A judge building this from a clean
# checkout in October would have got different libraries from the ones in the
# recorded demo, with no way to tell what changed.
#
# Raising a pin is a deliberate act: change the number, run the tests, and run
# `pip-audit -r requirements.txt` in a throwaway virtualenv (never in this one:
# a checking tool has no business in the environment it checks).
#
# ASCII only, deliberately. Both pip and pip-audit read this file with the
# machine's own locale encoding when it has no byte-order mark, so one em dash
# in a comment makes it unreadable on a Japanese Windows install (cp932) while
# working perfectly in the Linux container. A comment is not worth a file that
# only parses in some countries.
