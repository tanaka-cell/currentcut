CurrentCut

Rest after the shoot. Wake up to a first cut.

A director shoots a 5–15 minute factual feature, then spends the night alone with the footage: logging it, checking the numbers, drafting a structure. CurrentCut works that shift. By morning there is a first cut — and unlike an ordinary automatic rough cut, every factual line carries the source it was checked against, and off-record material has already been removed.

Runs for real: Gemini reads the footage, the Parallel Search API checks the claims that clear the confidentiality gate, FFmpeg cuts the preview. Takes about a minute.
