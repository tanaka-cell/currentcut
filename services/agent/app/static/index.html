    The script, line by line

    Every line points back to the timecode it came from. A number reaches a caption only when a retrieved page matched it on entity, attribute and value.

    What left the building

    Every outbound search is recorded before it is sent and again when it returns. Raw transcripts are never sent — only keyword queries built from public claims.

    Caption order sheet

    In a Japanese newsroom the director writes this in Excel (テロップ原稿) and the edit house pours it into the programme's template — so the spreadsheet is what CurrentCut produces, carrying the one column a director would otherwise fill in by hand: whether each figure was checked, against what.

    caption-sheet.xlsx — or as CSV
    Optional: upload your programme's own form (.xlsx, or a scan of the paper pad as JPEG/PNG/PDF) and CurrentCut fills that too, formatting intact.
